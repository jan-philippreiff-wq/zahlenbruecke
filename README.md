# Zahlenbrücke

Eine Übungsseite für ein SBBZ Lernen: Zehner-, Hunderter- und Tausenderübergang mit der Stopp-Methode. Große Kacheln, einfache Sprache, Schritt-für-Schritt-Hilfen und Aufgaben ohne Zeitdruck.

## Öffnen

`index.html` im Browser öffnen. Keine Installation nötig. Alle Dateien im selben Ordner behalten. Die Seite funktioniert auch offline.

`unterricht.html` enthält die vorbereitete 45-Minuten-Stunde, Differenzierung, Tafelbild, Kopiervorlagen, schriftliche Vertiefung und Lösungen. Über „Drucken / PDF“ ausdrucken oder als PDF speichern. Die Unterrichtsvorbereitung setzt den Schwerpunkt auf die Stopp-Methode; schriftliche Verfahren dienen der späteren Vertiefung.

## Kacheln

- Verliebte Zahlen mit Zehnerfeld (Fünferstruktur)
- Stellenwerte T, H, Z, E
- Tausch-Werkstatt: 998 legen und 10 gegen 1 tauschen; auch entbündeln
- Zehner-, Hunderter-, Tausenderübergang: Plus, Minus oder gemischt; wahlweise mit Zerlegung
- Verdoppeln und Fast-Verdoppeln
- Schriftlich rechnen mit erklärten Überträgen und Entbündeln, auch über Nullen

## Endboss

Jede Runde hat genau 10 verschiedene Aufgaben: 2 Zehner-, 3 Hunderter- und 5 Tausenderübergänge. Plus und Minus sind enthalten. Mindestens 8 erste geprüfte Antworten müssen stimmen. Jede Aufgabe wird nur einmal bewertet. Nach einem Fehler wird der Rechenweg gezeigt. Unter 8 richtigen Antworten kann eine neue zufällig erzeugte Runde gestartet werden. Ungültige oder leere Eingaben zählen nicht als Fehler. Es gibt keine Zeitbegrenzung und keine Sperre der Kacheln.

Übungssterne bedeuten „Runde bearbeitet“, nicht „Lernziel sicher erreicht“. Für den Boss gibt es einen Stern erst ab 8/10. Der Boss ist eine spielerische Übung, kein standardisierter Test.

## Daten

Keine Konten, keine Namenseingabe, kein Tracking-Code. Nur Übungssterne bleiben im lokalen Browser-Speicher. Antworten werden nicht dauerhaft gespeichert. Beim Neuladen geht die laufende Runde verloren. Browser-Speicher darf blockiert sein, ohne die Übungen zu verhindern. GitHub Pages verarbeitet beim Online-Aufruf die üblichen Verbindungsdaten.

## GitHub Pages

Unter Repository → Settings → Pages: „Deploy from a branch“, Branch `main`, Ordner `/ (root)`, Save. Die Startdatei ist `index.html`.

## Aufbau

Statische Dateien ohne Abhängigkeiten: `index.html`, `style.css`, `app.js`, `unterricht.html`. Keine Zugangsdaten im Code.
